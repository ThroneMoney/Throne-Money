# Fee Model

Throne Money uses a simple and transparent fee approach.

## User Fees (Draft)

| Fee Type            | Rate          | Notes                                      |
|---------------------|---------------|--------------------------------------------|
| Management Fee      | 0.5% – 1%/yr  | Taken from yield generated                 |
| Performance Fee     | 10% – 15%     | Only on profits above benchmark            |
| $THRONE Discount    | Up to 50%     | Based on holdings                          |

## Token Trading Fees (Bankr Native)

Because $THRONE is launched on Bankr:

- Every trade of $THRONE generates creator fees
- A large portion of those fees goes to the Throne Money agent wallet
- This creates a direct loop:

**More usage → More trading → More fees → Stronger agent → Better product**
