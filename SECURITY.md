# Security Policy

## Reporting a Vulnerability

If you discover a security issue related to Throne Money, please report it responsibly.

**Do not** open a public GitHub issue for security vulnerabilities.

Instead, contact us via:

- X: [@ThroneMoney](https://x.com/ThroneMoney)

Please include as much detail as possible so we can understand and address the issue quickly.

## Scope

Throne Money is currently an instructional skill for Bankr agents.  
It does not custody funds or execute transactions independently outside of the Bankr environment.

However, any issues related to:

- Misleading risk guidance
- Incorrect safety assumptions
- Potential for harmful recommendations

should still be reported.

## Response

We will review security reports as quickly as possible and take appropriate action.
