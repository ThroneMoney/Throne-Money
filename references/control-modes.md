# Control Modes

## 1. Full Sovereign
- Agent has authority to execute within the hard risk limits
- Still respects all non-negotiable risk rules
- User can revoke or switch modes at any time
- Recommended only for users who fully trust the current configuration

## 2. Co-Pilot (Default Recommended)
- Agent analyzes and proposes
- Any capital movement above threshold (default $100 or 2% of portfolio) requires explicit approval
- Best balance of convenience and control

## 3. Manual Override
- Agent only executes exactly what the user commands
- Still provides analysis, warnings, and Throne Scores
- Useful for precise interventions

## 4. Paper Throne
- All strategies run against live data but no real transactions are sent
- Perfect for testing allocation ideas and understanding behavior before risking capital

## Mode Switching

The user can switch modes at any time with a clear command.  
When switching into Full Sovereign, the agent should restate the current hard limits and ask for confirmation.
