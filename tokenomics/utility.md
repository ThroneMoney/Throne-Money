# Utility

## Primary Utilities of $THRONE

### 1. Fee Discount
Users who hold $THRONE get reduced fees when using Throne Money (management / performance fees).  
Discount can go up to **50%**, proportional to holdings.

### 2. Priority Access
- Priority access to Spec Throne opportunities
- Early access to new strategies and features
- Higher visibility inside the agent for high-conviction setups

### 3. Agent Alignment
Trading fees generated by $THRONE flow back to the Throne Money agent wallet.  
This allows the agent to:
- Fund its own compute / LLM costs
- Improve the system over time
- Remain self-sustaining

### 4. Skill Integration
The Throne Money skill automatically checks the user’s $THRONE balance on Base.  
If the user holds $THRONE, benefits are applied directly inside the agent.

### 5. Governance (Later Phase)
As the system matures, $THRONE holders can influence:
- Risk parameters
- Protocol whitelist
- Strategy priorities
