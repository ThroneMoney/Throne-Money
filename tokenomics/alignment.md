# Alignment Loop

The core economic loop of Throne Money:

1. Users use Throne Money to manage capital
2. $THRONE is traded and held for utility
3. Trading generates creator fees via Bankr
4. Fees flow to the Throne Money agent wallet
5. Agent uses resources to improve the system
6. Better system → more users → stronger loop

This is the Bankr agent economy model applied to a yield management skill.

Holding $THRONE strengthens alignment between the user and the agent.
